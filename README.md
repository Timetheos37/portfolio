# Portfolio Personnel | Personal Portfolio 🚀

Bienvenue sur le code source de mon portfolio ! Ce site bilingue (Français/Anglais) sert de vitrine pour mon parcours et mes projets en ingénierie informatique (Réseaux et systèmes, systèmes embarqués, etc.).

*Welcome to the source code of my portfolio! This bilingual (French/English) website showcases my background and computer engineering projects.*

## ✨ Fonctionnalités / Features

- 🌍 **Multilinguisme natif (FR/EN) :** Gestion du contenu via les *Collections Astro* avec un système de routage dynamique intelligent.
- ⚡ **Performance optimale :** Génération de site statique (SSG) hyper rapide grâce au framework Astro.
- 🎨 **Design moderne :** Intégration de [Webcore UI](https://webcoreui.dev/) (Carrousel) et gestion du mode Sombre/Clair.
- 📱 **Composants interactifs :** Carte de contact personnalisée avec copie dans le presse-papier en un clic via JavaScript natif.

## 🛠️ Stack Technique / Tech Stack

- Framework : [Astro](https://astro.build/)
- Langages : HTML, CSS (Sass), JavaScript / TypeScript
- Contenu : Markdown (.md)
